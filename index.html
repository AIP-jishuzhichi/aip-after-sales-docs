    下载 新窗口

    往仓库里放文件

    三种方式，按顺手程度挑一个。

    1

    网页上直接上传（最省事）

    打开 GitHub 仓库，进入 售后资料 里的某个分类文件夹，点 Add file → Upload files，把 PDF 拖进去提交即可。

    2

    拖到「①把PDF拖到我身上」

    在电脑上把 PDF 拖到这个文件图标上松手，它会自动归档、更新清单并上传到 GitHub。

    3

    命令行

    在项目文件夹里执行：

    python 维护脚本/添加文件.py "手册.pdf" --category 产品手册 --push

    文件清单 索引数据/documents.json 由脚本自动生成，不需要手动编辑。
